==============
Grid PDF Model
==============

This model was presented in Ref. :cite:alp:`Costantini:2024wby`.

**Model Respository:** https://github.com/HEP-PBSP/grid_pdf-model .

What is this model for?
-----------------------

This model can be used to benchmark the :ref:`bayesian fitting methodology <in_running_bayesian>`
with other methodologies. See :ref:`this section <in_running_fits>` for the different fitting
methodologies supported by Colibri.
